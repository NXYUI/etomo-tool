# etomo-tool

AI 채팅용 캐릭터/프롬프트 제작을 보조하는 Windows 데스크톱 앱입니다.<br>
하나의 프로젝트 폴더를 하나의 챗봇 작업 공간으로 사용합니다.<br>
프롬프트, 캐릭터 시트, 이미지 코드, 로어북을 같은 프로젝트 안에서 관리합니다.

## 라이선스

이 프로젝트는 [MIT License](LICENSE)에 따라 배포되는 오픈 소스 소프트웨어입니다.

## 주요 기능

- 프로젝트별 챗봇 작업 공간 관리
- 여러 프롬프트 탭 작성 및 자동 저장
- 텍스트 길이 제한, 마크다운 미리보기, 자동완성 키워드 관리
- 캐릭터별 코드, 표시 이름, 프로필 항목 관리
- 전역 캐릭터 시트 프리셋 관리
- `KEY=VALUE` 형식의 이미지 코드 파싱
- 캐릭터 코드별 이미지 등록, 삭제, 파일명 자동 변환
- 로어북 카드 관리, 호출어 등록, 우선순위 정렬
- 프로젝트 백업 및 새 프로젝트로 가져오기
- 전체 정리 화면에서 프로젝트 상태 확인

## 프로젝트 폴더 주의사항

> [!WARNING]
> 되도록 이미 존재하는 폴더를 프로젝트 폴더로 설정하지 마세요.<br>
> 새로운 폴더를 만들어서 설정한 다음에 기존 자료를 옮겨 주세요.<br>
> 앱 데이터와 해당 폴더의 기존 파일이 섞여 관리하기 어려울 수 있습니다.<br>
> 코드를 전부 검토하긴 했지만 파일 삭제의 위험도 있습니다.

프로젝트 폴더는 앱 데이터가 저장되는 실제 작업 폴더입니다.<br>
폴더 안에는 `etomo.project.json`과 캐릭터 코드별 이미지 파일 등이 생성됩니다.

## 이미지 코드 형식

이미지 코드 입력은 다음 형식을 인식합니다.

```text
평상시=001
웃음=002
식사=16,17,18
```

형식에 맞지 않는 줄은 무시됩니다.<br>
`식사=16,17,18`처럼 쉼표가 포함된 값은 각 숫자마다 별도의 이미지 카드로 분리됩니다.

이미지를 등록하면 선택한 캐릭터 코드 폴더 안에 이미지 코드 값 기준의 파일명으로 저장됩니다.

## 백업과 가져오기

앱은 현재 프로젝트 또는 전체 프로젝트 데이터를 `.etomo` 백업 파일로 내보낼 수 있습니다.

가져오기는 기존 프로젝트에 병합하거나 덮어쓰지 않고, 새 프로젝트로만 복원하는 방식을 사용합니다.<br>
기존 작업물을 실수로 덮어쓰는 상황을 피하기 위한 설계입니다.

## 설치

Windows 설치 파일은 프로젝트 관리자가 별도로 제공하는 배포 파일을 사용해 설치합니다.

## 데이터 저장

프로젝트 데이터는 사용자가 지정한 프로젝트 폴더 안의 `etomo.project.json`에 저장됩니다.<br>
앱을 삭제해도 프로젝트 폴더를 별도로 지우지 않는 한 해당 프로젝트 데이터는 폴더에 남습니다.
