# etomo-tool

AI 채팅용 캐릭터/프롬프트 제작을 보조하는 Windows 데스크톱 앱입니다. 하나의 프로젝트 폴더를 하나의 챗봇 작업 공간으로 사용하고, 프롬프트, 캐릭터 시트, 이미지 코드, 로어북을 같은 프로젝트 안에서 관리합니다.

## 배포 및 사용권

etomo-tool은 오픈 소스 소프트웨어가 아닙니다. 이 저장소에 접근할 수 있거나 소스 코드를 확인할 수 있더라도, 별도의 명시적인 허가 없이 소스 코드, 이미지, 아이콘, 빌드 산출물을 복제, 수정, 재배포하거나 상업적으로 사용할 수 없습니다.

별도의 라이선스 파일이 제공되지 않는 한 모든 권리는 저작권자에게 있습니다.

## 주요 기능

- 프로젝트별 챗봇 작업 공간 관리
- 여러 프롬프트 탭 작성 및 자동 저장
- 텍스트 길이 제한, 마크다운 미리보기, 자동완성 키워드 관리
- 캐릭터별 코드, 표시 이름, 프로필 항목 관리
- 전역 캐릭터 시트 프리셋 관리
- `KEY=VALUE` 형식의 이미지 코드 파싱
- 캐릭터 코드별 이미지 등록, 삭제, 파일명 자동 변환
- 로어북 카드 관리, 호출어 등록, 우선순위 정렬
- 프로젝트 백업 및 새 프로젝트로 가져오기
- 전체 정리 화면에서 프로젝트 상태 확인

## 프로젝트 폴더 주의사항

프로젝트 폴더는 앱 데이터가 저장되는 실제 작업 폴더입니다. 폴더 안에는 `etomo.project.json`과 캐릭터 코드별 이미지 파일 등이 생성됩니다.

되도록 이미 존재하는 폴더를 프로젝트 폴더로 설정하지 말고, 새로운 폴더를 만들어서 설정한 다음에 기존 자료를 옮겨 주세요. 기존 자료가 많은 폴더를 바로 프로젝트 폴더로 지정하면 앱 데이터와 사용자가 관리하던 파일이 섞여 관리하기 어려울 수 있습니다.

## 이미지 코드 형식

이미지 코드 입력은 다음 형식을 인식합니다.

```text
평상시=001
웃음=002
식사=16,17,18
```

형식에 맞지 않는 줄은 무시됩니다. `식사=16,17,18`처럼 쉼표가 포함된 값은 각 숫자마다 별도의 이미지 카드로 분리됩니다.

이미지를 등록하면 선택한 캐릭터 코드 폴더 안에 이미지 코드 값 기준의 파일명으로 저장됩니다.

## 백업과 가져오기

앱은 현재 프로젝트 또는 전체 프로젝트 데이터를 `.etomo` 백업 파일로 내보낼 수 있습니다.

가져오기는 기존 프로젝트에 병합하거나 덮어쓰지 않고, 새 프로젝트로만 복원하는 방식을 사용합니다. 기존 작업물을 실수로 덮어쓰는 상황을 피하기 위한 설계입니다.

## 설치

Windows 설치 파일은 프로젝트 관리자가 별도로 제공하는 배포 파일을 사용해 설치합니다.

오픈 소스로 취급합니다.

## 데이터 저장

프로젝트 데이터는 사용자가 지정한 프로젝트 폴더 안의 `etomo.project.json`에 저장됩니다. 앱을 삭제해도 프로젝트 폴더를 별도로 지우지 않는 한 해당 프로젝트 데이터는 폴더에 남습니다.
